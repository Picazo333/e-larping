# Agent Instructions — NEGRA — Tienda ejemplo

This store is built on Cloudflare Workers + D1 (generated by the e-larping store generator, Fase 3). It supports UCP natively.

## Discovery
- UCP profile: `/.well-known/ucp` (UCP version 2026-08-25)
- MCP endpoint: `/api/ucp/mcp` (JSON-RPC 2.0: initialize, tools/list, tools/call)
- Catalog: `/api/products`, `/products.json`, `/products/{handle}.js`
- Buy permalink: `/buy` (redirects to the cart)

## Tools (MCP)
- `catalog.search` — search products by text.
- `catalog.lookup` — one product by handle, with price and stock.
- `cart.create` — priced cart (volume tiers and per-product promos applied).
- `order.lookup` — one order by id.

## Rules for agents
- Prices shown are final in MXN; `compare_at_price` is the struck-through list price, never the charged price.
- Availability is verified BEFORE any charge. If stock is insufficient the order is refused with 409 and nothing is charged.
- Payment is handled by the store checkout, not by the agent. The UCP profile declares no payment handlers in v1 (no real payment adapter yet); the agent builds the cart and hands off to checkout.
- Fulfillment: shipping (Estafeta, FedEx; free over $2,000.00) or pickup at Punto NEGRA — CDMX, Calle Ejemplo 123, Col. Centro, Ciudad de México (Lun–Sáb 10:00–18:00).
- Returns: free within 30 days; refund in 3–5 días.
- Respect 429 with backoff and Retry-After. Do not script form submissions.
