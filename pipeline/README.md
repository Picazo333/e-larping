# Pipeline de generación de tienda

Pipeline reutilizable para generar una tienda de e-commerce de este tipo
desde cero y dejarla lista para despliegue final en Cloudflare.

Incluye:

- Base de datos (productos, pedidos, inventario).
- Webhooks (pedidos, pagos, stock).
- Flujos de procesos: respuesta automática de correos, registro y control
  de inventarios.

Se construye en la Fase 3, a partir de la síntesis de los 10 informes.
