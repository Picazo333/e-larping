# Informes por sitio

Un informe completo por cada e-commerce investigado (F4T3 + 9 más).

Cada informe cubre 7 dimensiones:

1. Front end — estructura, secciones, UX, checkout.
2. Back end + stack — observado vs inferido, con evidencia y confianza.
3. SEO/GEO y presencia digital.
4. Redes sociales + embudo — ritmos, screens, captions (método Cambridge).
5. Precios — promos, volumen, bundles/Mystery Box, efecto espera.
6. Logística — hipótesis derivada (inventarios, mensajería, costos).
7. Pain points — de qué se quejan los clientes.

La lista de los 9 sitios de la Fase 2 la aprueba Miguel antes de investigar.
